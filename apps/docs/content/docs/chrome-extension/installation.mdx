## Install from Chrome Web Store

<Steps>

### Visit the listing

Open the [Proxy App Chrome Web Store page](https://chromewebstore.google.com/detail/proxy-app/gdhjkolpmofllkogghodpnnmjajnbilg).

### Add to Chrome

Click **Add to Chrome** and confirm the permissions dialog. The extension will be installed immediately.

### Pin the extension

Click the **Extensions** button (puzzle piece icon) in the Chrome toolbar and click the pin icon next to **Proxy App**. This keeps the icon visible for quick access.

### Open the side panel

Click the **Proxy App** icon in the toolbar. The side panel opens on the right side of your browser window with the full workspace UI.

</Steps>

## Supported Browsers

Proxy App requires a Chromium-based browser with side panel support:

- **Google Chrome** 114+
- **Microsoft Edge** 114+
- **Brave** (latest)
- **Arc** (latest)

<Callout type="info">
Firefox and Safari are not supported because the extension relies on Chrome-specific APIs (`chrome.sidePanel`, `chrome.scripting` with `world: "MAIN"`).
</Callout>

## Updating

The extension updates automatically through the Chrome Web Store. You can check for updates manually:

1. Go to `chrome://extensions`
2. Enable **Developer mode** (toggle in the top right)
3. Click **Update** in the top left
