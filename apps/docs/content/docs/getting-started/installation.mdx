Proxy App is available as a **Chrome Extension** and a **Desktop App**. Choose the platform that fits your workflow.

## Chrome Extension

The Chrome Extension runs entirely inside the browser. No local server or additional software is required.

<Steps>

### Open the Chrome Web Store

Visit the [Proxy App listing](https://chromewebstore.google.com/detail/proxy-app/gdhjkolpmofllkogghodpnnmjajnbilg) in the Chrome Web Store.

### Click "Add to Chrome"

Click the **Add to Chrome** button and confirm the permissions dialog.

### Pin the extension

Click the puzzle-piece icon in the Chrome toolbar and pin **Proxy App** for quick access.

### Open the side panel

Click the Proxy App icon in the toolbar to open the side panel. You're ready to go.

</Steps>

## Desktop App (Electron)

The desktop app runs a local Express proxy server on your machine. Download the installer for your operating system.

### macOS

- **Apple Silicon (M1/M2/M3):** Download the `.dmg` file for `arm64`
- **Intel:** Download the `.dmg` file for `x64`

Open the `.dmg` and drag **Proxy App** to your Applications folder.

### Windows

- **Installer:** Download the `.exe` Setup file and run it
- **Portable:** Download the portable `.exe` to run without installing

### Linux

- **AppImage:** Download and make executable with `chmod +x`, then run
- **Debian/Ubuntu:** Download the `.deb` package and install with `sudo dpkg -i`
- **Fedora/RHEL:** Download the `.rpm` package and install with `sudo rpm -i`

### System Requirements

- **Node.js** is NOT required to run the packaged desktop app
- **macOS:** 10.15 (Catalina) or later
- **Windows:** Windows 10 or later
- **Linux:** Most modern distributions with `libfuse2` (for AppImage)
