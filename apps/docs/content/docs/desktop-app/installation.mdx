---
title: Desktop App Installation
description: Download and install the Proxy App desktop application.
---

The Proxy App desktop application is available for macOS, Windows, and Linux. Download the latest release from the GitHub releases page.

## macOS

### Apple Silicon (M1/M2/M3/M4)

Download the `arm64` DMG file:

```
Proxy App-{version}-arm64.dmg
```

Open the DMG and drag **Proxy App** to your **Applications** folder.

### Intel

Download the `x64` DMG file:

```
Proxy App-{version}-x64.dmg
```

<Callout type="info">
On first launch, macOS may show a security warning because the app is not signed with an Apple Developer certificate. Right-click the app and select **Open** to bypass this, or go to **System Settings → Privacy & Security** and click **Open Anyway**.
</Callout>

## Windows

### Installer

Download the NSIS installer:

```
Proxy App Setup {version}.exe
```

Run the installer and follow the prompts. The app is added to your Start menu.

### Portable

Download the portable executable:

```
Proxy App {version}.exe
```

No installation needed — run it directly from any folder.

## Linux

### AppImage (Universal)

```bash
chmod +x "Proxy App-{version}.AppImage"
./"Proxy App-{version}.AppImage"
```

<Callout type="warn">
AppImage requires `libfuse2`. On Ubuntu 22.04+, install it with `sudo apt install libfuse2`.
</Callout>

### Debian / Ubuntu

```bash
sudo dpkg -i proxy-app_{version}_amd64.deb
```

### Fedora / RHEL

```bash
sudo rpm -i proxy-app-{version}.x86_64.rpm
```

## System Requirements

| Platform | Minimum Version |
|----------|----------------|
| macOS | 10.15 (Catalina) |
| Windows | Windows 10 |
| Linux | Most modern distributions |

The packaged app includes all dependencies — Node.js is **not** required on the target machine.

## Building from Source

If you prefer to build from source:

```bash
git clone https://github.com/anteriovieira/proxy-app.git
cd proxy-app
pnpm install
pnpm --filter desktop build
```

Built files are placed in the `release/` directory. See the [build documentation](https://github.com/anteriovieira/proxy-app/blob/main/BUILD.md) for platform-specific instructions.
